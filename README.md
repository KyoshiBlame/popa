# popa

Учебный проект по имитационному моделированию обработки HTTP-запросов.

Основная логика находится в `simulation.py`: сервер моделируется как система массового обслуживания с ограниченным числом обработчиков и очередью ограниченного размера. Для генерации событий используется `SimPy`.

## Что делает проект

- моделирует входящий поток HTTP-запросов;
- учитывает время ожидания в очереди и время обслуживания;
- считает вероятность отказа при переполнении очереди;
- оценивает загрузку обработчиков;
- сохраняет таблицы и графики по результатам серии экспериментов.

## Эксперименты

В проекте исследуются:

1. влияние интенсивности входящего потока;
2. влияние числа обработчиков сервера;
3. влияние размера очереди.

Для каждой конфигурации выполняется несколько прогонов с разными `seed`, после чего считаются средние значения и 95% доверительные интервалы.

## Основные метрики

- среднее время ответа;
- 95-й перцентиль времени ответа;
- вероятность отказа;
- средняя и максимальная длина очереди;
- загрузка обработчиков.

## Структура

- `simulation.py` — основной код моделирования и построения графиков;
- `main.go` — минимальный HTTP-сервер на `Gin`;
- `results.zip` — архив с готовыми результатами;
- `results/` — CSV-файлы и графики, создаваемые после запуска симуляции.

## Запуск

Установить зависимости:

```bash
pip install simpy numpy pandas matplotlib scipy
```

Запустить моделирование:

```bash
python simulation.py
```

После выполнения результаты будут сохранены в папке `results/`.
